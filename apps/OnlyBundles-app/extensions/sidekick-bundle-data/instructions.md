# Only Bundles data

Use `search_bundles` to find bundles owned by Only Bundles in the current shop. Use `get_bundle_summary` when the merchant refers to a specific returned bundle.

Treat the returned fields as factual app data. Do not infer sales performance, inventory, customer information, or configuration that is absent from the response. Use the returned `app://` URL when the merchant wants to view or change a bundle. These tools only retrieve data and do not modify bundles.
