# Accessibility Checklist

Artifact job ID: fpb-all-template-summary-20260804
Artifact revision: 1
Artifact status: draft

- [ ] Correct semantics and accessible names.
- [ ] Selected, current, expanded, pressed, disabled, invalid, and busy state exposed.
- [ ] Keyboard-only completion in logical order.
- [ ] Focus visible, unclipped, and restored from overlays.
- [ ] State and errors not color-only.
- [ ] Dynamic totals, tiers, selections, and errors announced appropriately.
- [ ] Approved image alternative-text policy.
- [ ] Unique IDs.
- [ ] High zoom and long content operable.
- [ ] Reduced motion defined.
- [ ] Automated findings manually triaged.
